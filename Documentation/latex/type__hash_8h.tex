\doxysubsection{Description détaillée}
Implémentation des tables de hachage (déjà écrite, à utiliser pour les parcours de graphes). 

Ce fichier contient une implémentation déjà écrite des tables de hachage. Vous ne devez PAS LE MODIFIER. vous pouvez l\textquotesingle{}utiliser dans votre code pour stocker un ensemble détats déjà visités quand vous faites un parcours de graphe.

\begin{DoxyRemark}{Remarques}
La table de hachage est similaire à celle fournie dans le projet d\textquotesingle{}algorithmique. Elle ne peut stocker que des éléments encodés comme des tableaux d\textquotesingle{}entiers. Cela signifie que pour stocker des objets, vous devrez les encoder sous forme de tableaux d\textquotesingle{}entiers. De plus, la table de hachage ne stocke pas les éléments eux-\/mêmes, mais des indices vers un tableau de stockage externe que vous devez gérer vous-\/même. 
\end{DoxyRemark}

Tente d\textquotesingle{}insérer un élément dans la table de hachage. 

Si l\textquotesingle{}élément est déjà présent dans la table de hachage, l\textquotesingle{}insertion n\textquotesingle{}est pas effectuée. De plus l\textquotesingle{}indice du premier élément identique trouvé est stocké dans la variable pointée par ret (si ret n\textquotesingle{}est pas NULL).

\begin{DoxyRemark}{Remarques}
L\textquotesingle{}indice i fait référence à la position de l\textquotesingle{}élément dans le tableau de stockage externe. Puisque chaque élément est encodé comme une séquence d\textquotesingle{}entiers de taille fixe (le champ element\+\_\+size), la table de hachage va en fait examiner la séquence de element\+\_\+size valeurs entières commençant à la position i \texorpdfstring{$\ast$}{*} element\+\_\+size dans le tableau de stockage externe.
\end{DoxyRemark}
\begin{DoxyReturn}{Renvoie}
true si l\textquotesingle{}élément a été inséré, false s\textquotesingle{}il était déjà présent. Dans ce dernier cas, la table de hachage n\textquotesingle{}est pas modifiée. 
\end{DoxyReturn}
