\doxysubsection{Description détaillée}
Type utilisé pour représenter un noeud d\textquotesingle{}une expression régulière. 

Les champs left et right sont utilisés pour représenter les sous-\/expressions gauche et droite (si elles existent)\+:
\begin{DoxyItemize}
\item Pour les opérateurs unaire (COMPLEMENT et STAR), seul le champ left est utilisé.
\item Pour les opérateurs binaires (UNION, INTER et CONCAT), les deux champs sont utilisés.
\item Pour les opérandes (EMPTY, EPSILON et CHAR), aucun des deux champs n\textquotesingle{}est utilisé. Quand un champ n\textquotesingle{}est pas utilisé, il doit avoir la valeur NULL. 
\end{DoxyItemize}
