Conversion d'un graphe en une liste d'arrêtes.

Remarques
La taille de la liste est retournée par le second paramètre.
Attention
Cette fonction est utilisée pour la sauvegarde d'un NFA dans un fichier. Elle doit être écrite pour que la sauvegarde fonctionne correctement.
Renvoie
La liste des arrêtes.
Paramètres
GLe graphe à convertir.
sizePointeur pour retourner la taille de la liste.

multi_edge * ngraph_to_multi_edges ( ngraph * G,
int * size )

Calcul de la liste des multi-arêtes d'un graphe.

Renvoie
La liste des multi-arêtes stockée dans une pile.
Remarques
Cette fonction sert à afficher les automates de façon plus compacte : une fois écrite, les arêtes qui ont les mêmes extrémités peuvent être regroupées en une seule flèche. Pour utiliser cette fonction, il faut basculer à 1 la macro ADVANCED de parameters.h.
Paramètres
GLe graphe,
sizePointeur pour retourner la taille de la liste.
