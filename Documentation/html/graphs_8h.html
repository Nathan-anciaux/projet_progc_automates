Description détaillée

Implémentation des graphes étiquetés.

Contient le type utilisé pour représenter des graphes étiquetés (qu'on utilisera ensuite pour coder les transitions des automates).

Documentation des définitions de type

◆ ngraph

typedef struct ngraph ngraph

Type utilisé pour représenter un graphe orienté et étiqueté.

Le graphe contient nb_states sommets, numérotés de 0 à nb_states-1 et il y a nb_labels étiquettes numérotées de 0 à nb_labels-1. Les arrêtes sont codées par les deux tableaux "to_array" et "intervals":

  • "intervals" est un tableau de taille "nb_states * nb_labels + 1". Il stocke des indices dans le tableau "to_array" triés par ordre croissant.
  • "to_array" est un tableau d'entiers, qui stocke les états d'arrivée des arrêtes (sa taille est égale au nombre total d'arrêtes dans le graphe). Pour chaque état q et chaque étiquette a, les états d'arrivée des arrêtes partant de q et étiquetées par a sont stockées de façon contiguë et triés par ordre croissant dans le tableau "to_array", entre les indices intervals[q * nb_labels + a] (inclus) et intervals[q * nb_labels + a + 1] (exclus).
Remarques
En particulier, la cellule intervals[nb_states * nb_labels] contient le nombre total de transitions dans l'automate (la taille de intervals).
