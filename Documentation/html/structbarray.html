Description détaillée

Type utilisé pour représenter un tableau de Booléens.

Un tableau de Booléens est codé par un tableau de unsigned char. Chaque usigned char prend un octet en mémoire (8 bits) et peut donc stocker 8 Booléens.

L'implémentation est facilitée par les opérateurs de manipulation bit à bit |, &, ~, >> et <<.
