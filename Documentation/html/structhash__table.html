Description détaillée

Type utilisé pour représenter une table de hachage.

Utilisée pour stocker les configurations de plateau visitées dans le résolveur. La table de hachage ne stocke pas les objets eux-mêmes, mais des indices vers un tableau de stockage externe qui est passé aux fonctions de la table de hachage (ceci est nécessaire car le tableau de stockage externe peut avoir besoin d'être réalloué et déplacé en mémoire).

Remarques
Chaque élément inséré doit être encodé dans le tableau de stockage externe comme une séquence d'entiers (la longueur de la séquence est fixée à la création de la table de hachage). En particulier, cela signifie que les objets à insérer doivent être encodés comme des tableaux d'entiers.
