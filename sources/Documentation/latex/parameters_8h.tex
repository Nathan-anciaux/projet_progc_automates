\#define ADVANCED~0}



Cette macro influe sur l\textquotesingle{}affichage des automates. 


\begin{DoxyItemize}
\item Si elle est définie à 0, les transitions dont les extrémités sont les mêmes sont affichées comme plusieurs flèches (autant de flèches que de transitions).
\item Sinon, les transitions de mêmes extrémités sont regroupées en une seule flèche.
\end{DoxyItemize}

Pour utiliser la deuxième option, il est nécessaire d\textquotesingle{}avoir écrit la fonction \doxylink{graphs_8c_a4aaba843a99c319619e056acfbc9f951}{ngraph\+\_\+to\+\_\+multi\+\_\+edges()} du fichier \doxylink{graphs_8c}{graphs.\+c}.
