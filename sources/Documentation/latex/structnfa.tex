\doxysubsection{Description détaillée}
Type utilisé pour représenter un NFA. 

\begin{DoxyRemark}{Remarques}
Si l\textquotesingle{}automate ne possède pas de transitions epsilon, alors le champ nb\+\_\+letters est égal à transitions-\/\texorpdfstring{$>$}{>}nb\+\_\+labels (les étiquettes du graphe des transitions correspondent exactement aux lettres de l\textquotesingle{}alphabet de l\textquotesingle{}automate). Sinon, si il y a des transitions epsilon, alors transitions-\/\texorpdfstring{$>$}{>}nb\+\_\+labels = nb\+\_\+letters + 1
\begin{DoxyItemize}
\item Les étiquettes de 0 à nb\+\_\+letters-\/1 correspondent aux lettres de l\textquotesingle{}alphabet.
\item L\textquotesingle{}étiquette nb\+\_\+letters correspond aux transitions epsilon.
\end{DoxyItemize}

Le tableau des noms des états n\textquotesingle{}est pas toujours utilisé (dans ce cas le nom d\textquotesingle{}un état est simplement son numéro). Si on ne l\textquotesingle{}utilise pas, il doit avoir la valeur {\ttfamily NULL}. Quand on l\textquotesingle{}utilise, chaque nom d\textquotesingle{}état est une chaîne de caractères allouée dynamiquement (il faudra donc penser à libérer ces chaînes ainsi que le tableau des noms des états quand on n\textquotesingle{}en a plus besoin). 
\end{DoxyRemark}
