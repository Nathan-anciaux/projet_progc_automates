void multiple\+\_\+free (\begin{DoxyParamCaption}\item[{void \texorpdfstring{$\ast$}{*}}]{p}{, }\item[{}]{...}{}\end{DoxyParamCaption})}



Fonction pour libérer de la mémoire en utilisant la fonction free(). 

Appelle free sur un nombre variable d\textquotesingle{}arguments. Le dernier argument doit être NULL.

Exemple d\textquotesingle{}utilisation \+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keywordtype}{int}\ *p1,\ *p2,\ *p3;}
\DoxyCodeLine{}
\DoxyCodeLine{\mbox{\hyperlink{alloc_8h_aea7a1b86d2684b290ef0ecd63623c19b}{CREATE\_MEMORY}}(p1,\ 10);\ \textcolor{comment}{//\ Alloue\ un\ tableau\ de\ 10\ int.}}
\DoxyCodeLine{\mbox{\hyperlink{alloc_8h_aea7a1b86d2684b290ef0ecd63623c19b}{CREATE\_MEMORY}}(p2,\ 10);}
\DoxyCodeLine{\mbox{\hyperlink{alloc_8h_aea7a1b86d2684b290ef0ecd63623c19b}{CREATE\_MEMORY}}(p3,\ 10);}
\DoxyCodeLine{\textcolor{comment}{//\ ...}}
\DoxyCodeLine{\mbox{\hyperlink{alloc_8c_a95dd19b1b2af33029f7ccb78d5f17039}{multiple\_free}}(p1,\ p2,\ p3,\ NULL);}

\end{DoxyCode}


\begin{DoxyAttention}{Attention}
Cette fonction est dangereuse et il faut savoir ce que vous faites si vous l\textquotesingle{}utilisez ! Les pointeurs à libérer {\bfseries{ne doivent pas}} être NULL. Dans l\textquotesingle{}exemple précédent, si {\ttfamily p2} est NULL, on ne libère pas {\ttfamily p3} et cela peut créer une fuite mémoire. 
\end{DoxyAttention}
