\doxysubsection{Description détaillée}
Type utilisé pour représenter une multi-\/arête. 

Une multi-\/arête relie deux sommets et peut porter plusieurs étiquettes. Utilisé uniquement dans l\textquotesingle{}affichage avancé des automates pour simplifier la représentation graphique.

\begin{DoxyRemark}{Remarques}
Une multi-\/arête est une arête qui peut avoir plusieurs étiquettes. On se sert de ce type pour l\textquotesingle{}affichage \+: quand deux sommets sont reliés par plusieurs arêtes, on simplifie la présentation en ne dessinant qu\textquotesingle{}une seule arête qui porte toutes les étiquettes des vraies arêtes. 
\end{DoxyRemark}
