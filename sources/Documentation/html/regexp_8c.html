◆ reg_issimple()

bool reg_issimple ( regexp * )

Teste si une expression régulière est simple.

Remarques
Une expression régulière est simple si et seulement si elle ne contient pas les opérateurs "interection" et "complément".
Renvoie
Un Booléen indiquant si l'expression passée en entrée est simple.
