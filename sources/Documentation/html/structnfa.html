Description détaillée

Type utilisé pour représenter un NFA.

Remarques
Si l'automate ne possède pas de transitions epsilon, alors le champ nb_letters est égal à transitions->nb_labels (les étiquettes du graphe des transitions correspondent exactement aux lettres de l'alphabet de l'automate). Sinon, si il y a des transitions epsilon, alors transitions->nb_labels = nb_letters + 1
  • Les étiquettes de 0 à nb_letters-1 correspondent aux lettres de l'alphabet.
  • L'étiquette nb_letters correspond aux transitions epsilon.
Le tableau des noms des états n'est pas toujours utilisé (dans ce cas le nom d'un état est simplement son numéro). Si on ne l'utilise pas, il doit avoir la valeur NULL. Quand on l'utilise, chaque nom d'état est une chaîne de caractères allouée dynamiquement (il faudra donc penser à libérer ces chaînes ainsi que le tableau des noms des états quand on n'en a plus besoin).
