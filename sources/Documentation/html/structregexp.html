Description détaillée

Type utilisé pour représenter un noeud d'une expression régulière.

Les champs left et right sont utilisés pour représenter les sous-expressions gauche et droite (si elles existent):

  • Pour les opérateurs unaire (COMPLEMENT et STAR), seul le champ left est utilisé.
  • Pour les opérateurs binaires (UNION, INTER et CONCAT), les deux champs sont utilisés.
  • Pour les opérandes (EMPTY, EPSILON et CHAR), aucun des deux champs n'est utilisé. Quand un champ n'est pas utilisé, il doit avoir la valeur NULL.
