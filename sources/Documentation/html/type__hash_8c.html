◆ hash_table_insert()

bool hash_table_insert ( hash_table * ht,
int * elements,
int i,
int * ret )

Tente d'insérer un élément dans la table de hachage.

Si l'élément est déjà présent dans la table de hachage, l'insertion n'est pas effectuée. De plus l'indice du premier élément identique trouvé est stocké dans la variable pointée par ret (si ret n'est pas NULL).

Remarques
L'indice i fait référence à la position de l'élément dans le tableau de stockage externe. Puisque chaque élément est encodé comme une séquence d'entiers de taille fixe (le champ element_size), la table de hachage va en fait examiner la séquence de element_size valeurs entières commençant à la position i * element_size dans le tableau de stockage externe.
Renvoie
true si l'élément a été inséré, false s'il était déjà présent. Dans ce dernier cas, la table de hachage n'est pas modifiée.
Paramètres
htLa table de hachage.
elementsTableau de stockage externe contenant tous les éléments.
iIndice de l'élément à insérer dans le tableau de stockage externe.
retPointeur vers un entier où sera stocké l'indice de l'élément existant (si déjà présent).
